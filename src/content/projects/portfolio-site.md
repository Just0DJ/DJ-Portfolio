## Project Overview

This site — designed, architected, and developed end-to-end as a responsive web portfolio presenting mechanical design workflows, CAD models, and simulation case studies.

## Architecture

**Content Collections:** Projects and experiences live as markdown content collections; adding a project is a single file that automatically appears in the carousels, modal, sitemap, and gets its own dedicated case-study page.

**Performance:** All images flow through build-time optimization (automatic WebP, responsive `srcset`, hashed immutable URLs). Static site generation — no client framework, no backend.

**Accessibility:** Native `<dialog>` modal with focus trapping and Escape handling, keyboard-operable cards, `prefers-reduced-motion` support throughout.
